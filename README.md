
The increasing frequency of international transactions and travel has made real-time currency conversion essential for users. Mobile devices have become a primary tool for checking live exchange rates. This project focuses on building a simple, fast, and accurate mobile application that delivers real-time exchange rates and conversion service using a reliable currency API. The app is fully developed in Flutter, providing cross platform support.
